# CLAUDE.md — react-mockups

## Stack
Vite + React 18 + TypeScript, CSS Modules.

| Task        | Command              |
|-------------|----------------------|
| Dev server  | `npm run dev`        |
| Build       | `npm run build`      |
| Type-check  | `npx tsc -b`         |

## Layout (`src/`)
- `pages/<page>/` — one folder per page: `<Page>.tsx`, `<page>.module.css`, `mock.ts`
- `components/` — shared UI components
- `api/` — `schema.d.ts` is generated by `npm run gen:api` (don't edit it); other files are hand-written
- `lib/` — shared utilities
- `styles/` — global CSS tokens / resets
- `shaders/` — GLSL/Three.js shaders
- `data/` — shared static data

Pages: about-briefing, about-dossier, acquisitions, acquisitions-ladder,
data_availability, events, events-swimlanes, processors, release-log, version-matrix.

## Rules
- **Mock-ups only.** Each page's data lives in its `mock.ts`. Never read the large
  data blocks (e.g. `SPECS` in `src/pages/events/mock.ts`); read only types,
  constants, and helpers.
- **Match `docs/` references** (e.g. `docs/events-prototype-ref.md`) exactly. Never
  decode `../../documentation/SentiBoard.html` yourself.
- **No subagents for small tasks** — use grep/read directly.
- **Stay in this folder** — do not touch files outside `react-mockups/`.

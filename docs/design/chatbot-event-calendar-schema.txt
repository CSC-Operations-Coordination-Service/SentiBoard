Artifact Fetch Latency
The data retrieved by this endpoint is prepared by the backend's OpenSearch tool services during POST /chat, so it should normally respond quickly, something along the lines of one second. This endpoint only retrieves data that has already been prepared, so the latency should be very short.

Session Behaviour and Timeout
There is currently no configured inactivity timeout for backend chat sessions. Conversations and their visualisation data are stored in the PostgreSQL database and remain available until they are explicitly removed. A formal retention duration has not yet been defined. Editing and replaying earlier conversation turns is not supported in the current version. The chatbot has access to the last 12 turns (6 user messages and 6 replies); older messages are retained but do not influence the chatbot. Streamlit waits up to 360 seconds for each API request, including POST /chat. Each individual LLM request made by the backend has a 180-second timeout. OpenSearch requests have a 120-second timeout by default.
